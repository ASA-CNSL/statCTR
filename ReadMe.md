# StatCTR website

This is a Quarto website for the statistical consulting training resources initiative. The website is hosted at www.statCTR.com.

## Annual maintenance process

### Fix all "Issues" 

### Check for New Submissions 

- Check for new resource submissions [here](https://docs.google.com/spreadsheets/d/1qO4yLswCyyrHfK6UmzUTajzHOzUSnwO_dlofOYF4hOc/edit?gid=795109231#gid=795109231)
- Check for new video submissions [here](https://docs.google.com/spreadsheets/d/1FyySnon6m8YgjM0cp9MKkf37DB04aBSAqlD-WXpD8tk/edit?resourcekey=&gid=1910217701#gid=1910217701)

(you may need to request access to these from the owner)

### Send new submissions to ASA CNSL Chair for approval

- For resources, Chair should ensure the resource is sufficient quality and fit for the Section
- For videos, Chair should employ the [rubric](videorubric.pdf), and suggest approval, stipulations, or rejection. 
- This decision can be denoted in the final column of [the video submissions](https://docs.google.com/spreadsheets/d/1FyySnon6m8YgjM0cp9MKkf37DB04aBSAqlD-WXpD8tk/edit?resourcekey=&gid=1910217701#gid=1910217701)
- All rows with "Yes" will get added to the website. 

### Locally knit website pulling in new submissions

- You will need to allow Tidyverse API packages to access your google account. This can be changed later. 

### Spot check new submissions, ensure no errors & proper formatting

### Update Copyright Year in `_quarto.yml`

### Push website to GitHub Repo

### Ensure GitHub Page gets updated 

- This can take a few minutes.
- Check www.statCTR.com is correctly using the right copyright year.
- If statCTR.com is down, navigate to https://github.com/ASA-CNSL/statCTR/settings/pages to check that the website has been published correctly. You may have to do some troubleshooting.
